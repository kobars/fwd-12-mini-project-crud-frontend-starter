# Gambar pratinjau

Kedua gambar berikut dibuat khusus untuk pratinjau ini menggunakan image_gen tanpa gambar referensi.

- `assets/design-workspace.png`: ilustrasi fotografis ruang kerja desain dengan aksen hijau.
- `assets/study-workspace.png`: ilustrasi fotografis ruang belajar dengan aksen biru.

Gambar merupakan ilustrasi data contoh. Gambar bukan tangkapan layar produk, bukti materi kursus, atau foto pemilik produk. Data dengan thumbnail kosong menampilkan keterangan gambar belum tersedia.

Sampul buku dari versi sebelumnya tidak termasuk dalam paket ini.
